LiveMusicApp – Source Code & Script Documentation

C Source Files (src/)

These files constitute the core of the LiveMusicApp application. Each file is responsible for a specific functional area, from MIDI handling to UI widgets.

  • APlayMidi.c – Implements MIDI playback using the ALSA sequencer.
  • LiveMusicApp.c – Entry point and main event loop of the application.
  • SooperOSC.c – Handles Open Sound Control (OSC) messaging for remote control.
  • AlsaUtils.c – Small utility library for ALSA MIDI operations (device enumeration, config).
  • MyWidgets.c – Definition of custom GTK+ widgets used in the UI.
  • Timers.c – Management of high‑resolution timers and scheduled callbacks.
  • Connections.c – Implements the internal “connection” graph that links UI actions to audio processes.
  • Chorder.c – Generates chord progressions based on user‑defined rules.
  • Player.c – Core audio playback engine; handles buffering, effects, and output.
  • HTML.c – Utilities for generating static HTML snippets (e.g., song listings).
  • RightMenuClick.c – Callback for right‑mouse context menu generation.
  • HIDGrab.c – Reads input from human‑interface devices (e.g., MIDI keyboards, control surfaces).
  • PrefsFile.c – Persistent storage of user preferences (JSON‑based).
  • PrefsGui.c – GUI front‑end for editing preferences.
  • Transport.c – Controls global transport (play, stop, record, loop).
  • XMLReader2.c – Robust XML parser used for importing/exporting song metadata.
